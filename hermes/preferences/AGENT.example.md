# Docket agent preferences

This is an operator-authored preference database for how Hermes should work
with the operator. Keep durable habits and interaction preferences here. Exact
calendar events, schedules, deadlines, and other mutable operational facts
belong in Docket instead.

## Interaction

- Prefer concise, natural-language responses and let Docket cards carry durable
  proposal details and controls.

## Defaults

- Use Docket's configured timezone and calendar profile when the operator omits
  those values.
